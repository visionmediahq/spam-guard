# Security

Report a vulnerability through GitHub's private vulnerability reporting on this repository
(Security → Report a vulnerability). Do not open a public issue.

Fixes are prepared in a draft security advisory and its private fork, released as a patch tag,
rolled out to the sites, and then the advisory is published.

The thresholds (rate limit, content rules, ALTCHA difficulty) are readable in this repository by
design; the guard does not rely on them being secret.
